# PAUK VPN для Android

Это сборочный набор приложения PAUK на основе v2rayNG 2.2.6 по лицензии GPL-3.0. Сборка добавляет оформление PAUK, главный экран подключения, обновление подписки и геометрическую иконку.

![Иконка приложения PAUK](assets/pauk-app-icon-preview.png)

Чтобы собрать тестовый APK, откройте **Actions → Build PAUK VPN APK v1.1 → Run workflow**. Ссылка подписки в приложение не встраивается: клиент добавляет свою подписку PAUK сам.

Идентификатор Android-приложения и локальный ID устройства сохранены. Чтобы обновить уже установленную копию поверх, APK должен быть подписан тем же ключом; сборки GitHub Actions могут иметь другую подпись. В таком случае Android потребует удалить прежнюю копию, а затем добавить подписку заново. На экране, иконке запуска и уведомлении VPN отображается PAUK.
