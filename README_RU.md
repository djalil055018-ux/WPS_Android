# WPS VPN v10 — максимально простой клиент

Версия v10 построена на уже рабочей версии v9 и меняет только интерфейс, безопасные отступы и иконку. Логика пользовательской подписки и VPN-соединения сохранена.

## Что изменено

- полностью удалена шестерёнка настроек сверху;
- полностью удалена нижняя вкладка «Настройки»;
- клиенту оставлены только «Главная» и «Журналы»;
- главный экран защищён от выреза камеры, status bar и системной панели навигации;
- заголовок `WPS / VPN` опущен ниже системной области и больше не должен обрезаться;
- кнопки «Изменить ключ» и «Удалить ключ» выровнены в одну строку;
- длинный текст внутри кнопок может занимать две строки и не выходит за границы;
- основной экран прокручивается на небольших телефонах;
- создана новая компактная adaptive icon с безопасными внутренними полями;
- встроенного ключа нет;
- клиент добавляет, заменяет и удаляет только свою ссылку подписки;
- выбор сервера, импорт подписки и подключение выполняются автоматически.

## Что доступно клиенту

1. Добавить ключ.
2. Изменить ключ.
3. Удалить ключ.
4. Подключить или отключить VPN.
5. Открыть журнал для диагностики.

Ручные параметры транспорта, DNS, маршрутизации и прокси через интерфейс WPS не показываются.

## Обновление существующего репозитория v9

### 1. Загрузите патчер

Загрузите файл:

`tools/patch_v2rayng_v10.py`

в папку `tools` вашего GitHub-репозитория.

### 2. Загрузите workflow

Загрузите файл:

`.github/workflows/build-apk-v10.yml`

в папку `.github/workflows`.

### 3. Замените папку assets

Замените старые файлы иконок файлами из папки `assets` этого комплекта. В корне репозитория должны быть:

- `assets/wps_logo.png`
- `assets/wps_launcher_foreground.png`
- `assets/wps_icon_preview.png`
- `assets/icons/mipmap-mdpi/...`
- `assets/icons/mipmap-hdpi/...`
- `assets/icons/mipmap-xhdpi/...`
- `assets/icons/mipmap-xxhdpi/...`
- `assets/icons/mipmap-xxxhdpi/...`

### 4. Запустите новую сборку

Откройте GitHub → Actions и выберите:

`Build WPS VPN APK v10`

Нажмите `Run workflow`, выберите ветку `main` и снова нажмите `Run workflow`.

Не используйте `Re-run jobs` у старой сборки v9.

## Как проверить версию

В журнале должны появиться строки:

- `Workflow marker v10`
- `Apply WPS client-simple UI v10`
- `WPS patch version: v10-client-simple-safe-ui`
- `WPS v10 UI applied: settings removed, cutout-safe layout, two-button navigation, compact adaptive icon.`

## Готовый APK

После успешной сборки скачайте артефакт:

`WPS-APK-v10`

Внутри будет:

- `WPS-test.apk`
- `WPS-test.apk.sha256`

## Примечание об Android

Системное разрешение на создание VPN и постоянное системное уведомление во время работы VPN являются обязательными требованиями Android. Они не относятся к внутренним настройкам приложения.
